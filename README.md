# track-it-sis

Track It™, a free 30-day scalp journal. A project of Beyond the Hairline™ and Chat Chew and Do Empowerment Women Group (CCDEW).

Static site: `index.html` (the journal), `privacy.html`, `terms.html`. Fonts are self-hosted under `fonts/`. Journal entries are kept in the visitor's browser local storage; only the first name and email from the sign-up form are sent off-device.
